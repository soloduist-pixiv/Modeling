# 使用示例（math-paper-comprehend）

## 示例 1：完整精读

**用户：**「用 Comprehend 深度解析这篇数模论文」+ 粘贴/附上 PDF。

**Agent 行为：**
1. 打开本 skill 与所需 references  
2. 扫全文 → 输出完整性清单（全部模型 + 全部检验）  
3. 按一→二→三→四写满；模型节数=清单 N，检验节数=清单 M  
4. 交稿自检全部勾选后再回复  

## 示例 2：只有摘要

**用户：**只给摘要。

**Agent：**完整性清单标「待正文确认」；推断处写【推测】；请用户补全文后再把遗漏模型/检验补全。

## 示例 3：耦合模型必须拆开

论文写「熵权-TOPSIS」。

**正确：**清单含「熵权法」「TOPSIS」两节，各写 2.1–2.6，并写清权重如何进入贴近度。  
**错误：**一节「熵权-TOPSIS」里两句带过。

## 示例 4：结果表里的隐藏检验

正文无「假设检验」小节，但表中有 p 值、R²。

**正确：**检验清单列出对应方法，按 3.1–3.5 展开，数值引自该表。  
**错误：**因无独立章节而宣布「本文无检验」。

## 示例 5：分步

**用户：**「先分析问题和前两个模型」。

**Agent：**清单仍列全；本章只展开问题 + 模型 1–2；其余标「待续」。
