# 检验与诊断参考（math-paper-comprehend）

由 [`../SKILL.md`](../SKILL.md) 在解读检验/诊断时打开；勿单独当作完整导读流程。

使用原则：讲解必须绑定论文中的**原假设/对照物/作用对象**。出现 p 值时写清「拒绝了什么、没证明什么」。  
论文结果表里出现的每一个 p / R² / AUC / CR / 灵敏度曲线，只要支撑结论，就必须进入检验清单并单独展开。

## 1. 经典假设检验

### 1.1 t 检验（单样本 / 两独立样本 / 配对）

- **概念**：在正态（或大样本近似）下，检验均值是否等于某值或两组均值是否相同。  
- **思路**：用均值差相对标准误的大小判断是否像「偶然波动」。  
- **起效**：构造 t 统计量 → 对照 t 分布得 p 值；配对版先对差分再检验。  
- **优点**：简单、效力在假设满足时足够。  
- **局限**：偏态/异方差/非独立会失真；显著≠效应大；多样本两两 t 需多重比较校正。

### 1.2 方差分析 ANOVA / Kruskal–Wallis

- **概念**：多组均值（或分布位置）是否至少有一组不同。  
- **思路**：组间变异 vs 组内变异。  
- **起效**：F 检验（ANOVA）或秩次版本（KW）。  
- **优点**：先总检再两两比较，控制乱两两比对。  
- **局限**：ANOVA 要方差齐性等；显著后须事后检验；仍非因果。

### 1.3 卡方检验 / Fisher 精确检验

- **概念**：分类变量独立性或拟合优度。  
- **思路**：观察频数 vs 独立假设下的期望频数。  
- **起效**：χ² 统计量或精确枚举（小样本 Fisher）。  
- **优点**：列联表标准工具。  
- **局限**：期望频数过小要改用 Fisher/合并；显著只说「不独立」，不自动给出机制。

### 1.4 正态性、方差齐性（Shapiro–Wilk、Levene 等）

- **概念**：检查后续参数检验的前提。  
- **思路**：样本是否像来自正态；各组方差是否近似相同。  
- **起效**：专用统计量 + p 值；或图示（Q-Q）。  
- **优点**：避免「前提不成立还硬用 t/ANOVA」。  
- **局限**：大样本时「显著非正态」几乎必然，需结合图与稳健方法；检验本身也有误差。

### 1.5 非参数：Mann–Whitney / Wilcoxon / Spearman / Kendall

- **概念**：少依赖分布形状的位置或单调相关检验。  
- **思路**：用秩代替原始值，抗异常值与轻度偏态。  
- **起效**：秩统计量的零分布 → p 值；相关则测单调协会。  
- **优点**：假设更弱，竞赛小样本常用。  
- **局限**：效力可能低于正确设定的参数检验；Spearman 显著≠线性、更≠因果。

## 2. 回归诊断与参数相关检验

### 2.1 系数显著性（t / Wald / 似然比）

- **概念**：检验某系数是否为 0（或是否等于约束值）。  
- **思路**：估计值相对其标准误是否足够大；或比较嵌套模型拟合。  
- **起效**：t/Wald 用点估计与 SE；LRT 用两次对数似然差。  
- **优点**：直接对应「这个变量有没有解释力」的常见叙事。  
- **局限**：共线时 SE 膨胀导致「该显著不显著」；多重测试膨胀假阳性；显著≠实际重要。

### 2.2 拟合优度：R² / Adj-R² / 伪 R² / Deviance

- **概念**：模型解释了多少变异，或相对饱和/空模型好多少。  
- **思路**：把拟合质量压成一个可比较的标量。  
- **起效**：SSR/SST 等定义；广义线性用偏差或伪 R²。  
- **优点**：直观、便于模型间粗比。  
- **局限**：R² 高可因过拟合或泄漏；不同模型伪 R² 不可盲目横比；从不单独证明因果。

### 2.3 信息准则 AIC / BIC

- **概念**：拟合优度惩罚复杂度，用于模型选择。  
- **思路**：更好的模型 = 够准且够省参数。  
- **起效**：\-2 logLik + 惩罚项（BIC 对 n 更重罚）。  
- **优点**：同数据同似然框架下可排序。  
- **局限**：绝对数值无普适阈值；样本外表现仍以 CV/持出为准更稳。

### 2.4 多重共线性：VIF / 条件指数

- **概念**：自变量能否被其他自变量线性表出。  
- **思路**：共线使系数标准误变大、符号乱跳。  
- **起效**：VIF = 1/(1-R²_j)；经验阈值（如 >5 或 >10）需结合领域。  
- **优点**：解释「系数为啥不稳」。  
- **局限**：阈值教条；有共线仍可能预测好；解决靠合并/正则/换问题，不靠无视。

### 2.5 残差诊断（异方差、自相关、杠杆点）

- **概念**：检查误差假设：齐方差、独立、无强影响点。  
- **思路**：模型错了往往先在残差里露出马脚。  
- **起效**：残差图、Breusch–Pagan、DW/ACF、Cook 距离等。  
- **优点**：防止「系数表好看但假设崩盘」。  
- **局限**：图示判读有主观；时序必须查自相关，否则推断无效。

### 2.6 模型总体检验：F 检验 / Omnibus

- **概念**：是否「所有斜率全为 0」。  
- **思路**：相对只含截距的空模型，是否整体有解释力。  
- **起效**：均方回归 vs 均方残差。  
- **优点**：总开关；不显著则单系数叙事要收敛。  
- **局限**：总体显著仍可能满篇无用变量；大样本易「万事皆显著」。

## 3. 分类与预测性能验证

### 3.1 混淆矩阵、Precision / Recall / F1 / Specificity

- **概念**：从预测类与真实类交叉表导出的性能指标。  
- **思路**：不同类型错误成本不同，不能只看准确率。  
- **起效**：TP/FP/TN/FN → 各比率。  
- **优点**：揭示类别不平衡下的虚高准确率。  
- **局限**：阈值依赖；要报告选阈值依据。

### 3.2 ROC / AUC / PR 曲线

- **概念**：遍历阈值看排序能力；AUC 是综合标量。  
- **思路**：好模型让正类得分整体高于负类。  
- **起效**：TPR-FPR 曲线下面积；极端不平衡更宜看 PR。  
- **优点**：少受单一阈值绑架。  
- **局限**：AUC 高未必业务可部署；泄漏会制造梦幻 AUC。

### 3.3 交叉验证 K-fold / LOO / 分组 CV

- **概念**：轮流持出估计泛化误差。  
- **思路**：不拿训练误差吹牛。  
- **起效**：分割 → 训练 → 测试 → 平均；分组 CV 按实体/时间块切。  
- **优点**：小样本下更诚实。  
- **局限**：普通随机 K-fold 对时序/重复测量会泄漏；LOO 方差大、算力贵；预处理器必须放进 fold 内。

### 3.4 时间序列持出 / 滚动原点评估

- **概念**：只用过去拟合、用未来评估。  
- **思路**：模拟真实预报。  
- **起效**：expanding/rolling window。  
- **优点**：防时间泄漏的底线。  
- **局限**：结构突变期表现差不能单靠换模型粉饰。

## 4. 重采样、置换与不确定性

### 4.1 Bootstrap

- **概念**：有放回重抽样逼近估计量的抽样分布。  
- **思路**：数据是总体的代理。  
- **起效**：重复估计 → 置信区间 / 稳定性频率。  
- **优点**：聚类支持度、系数区间、小样本很常用。  
- **局限**：样本不代表总体则自助无用；依赖独立假设；区间覆盖率非魔法。

### 4.2 置换检验 / 标签随机化

- **概念**：在 H0（如无关联、无组差）下重排标签，看统计量有多极端。  
- **思路**：用经验零分布代替参数零分布。  
- **起效**：计算观测统计量 → 多次置换 → p = 极端比例。  
- **优点**：假设弱、适合复杂统计量。  
- **局限**：交换性要成立；计算量大；设计置换单位（样本点 vs 整簇）必须正确，否则 p 值骗人。

### 4.3 蒙特卡洛模拟 / 扰动灵敏度

- **概念**：对参数或输入加噪，看输出分布。  
- **思路**：结论若只在针尖参数上成立，则不可信。  
- **起效**：采样参数 → 重求解 → 汇总。  
- **优点**：优化/机理模型几乎必备。  
- **局限**：「只扰动 ±10%」可能避开真风险；应优先扰动**关键假设与约束**，而不只是微扰数字。

## 5. 多重比较、信息泄漏与「假稳健」

### 5.1 Bonferroni / FDR（BH）

- **概念**：控制一族假设里的假阳性。  
- **思路**：检验越多，越要更严的阈值或估计假发现率。  
- **起效**：p 值校正或按序比较。  
- **优点**：相关矩阵、多指标两两检验时防「星号狩猎」。  
- **局限**：Bonferroni 过保守；FDR 允许一定假发现——要在论文里说清控制的是哪一族。

### 5.2 数据泄漏检查清单（导读时主动扫描）

| 泄漏源 | 典型症状 | 讲解时应指出 |
|--------|----------|--------------|
| 全数据标准化再划分 | 虚高 CV | 预处理必须 fold 内 |
| 时序随机打乱 | 虚高预报 | 必须时间持出 |
| 用测试信息选模 | 选模偏差 | 嵌套 CV / 独立测试 |
| 同一实体进出训练测试 | 伪独立 | 按组划分 |

### 5.3 「稳健性」常见注水

- 只改无关紧要的超参却称稳健  
- 只报告有利的灵敏度曲线  
- 把训练集指标当泛化  
- 用同一检验的 p 值叙事因果  

导读写到灵敏度/稳健性章节时，用上表主动打分：真稳健 / 弱稳健 / 疑似注水。

## 6. 评价类模型常见「检验」表述

竞赛论文里常把下列内容称为检验——按检验模板写，但点明其真实身份：

| 名称 | 真实身份 | 讲解要点 |
|------|----------|----------|
| AHP 一致性 CR | 主观判断自洽性 | CR<0.1 是惯例非物理定律 |
| 熵权稳定性 | 删样本后权重波动 | 要用重采样说话 |
| TOPSIS 排序灵敏度 | 权重/方案扰动下名次 | 名次跳变=结论脆 |
| 灰色关联分辨系数灵敏度 | 超参敏感 | 系数主观需坦白 |

## 7. 写作提示（给 Agent）

1. 先给方法归类：假设检验 / 拟合选择 / 预测验证 / 重采样 / 灵敏度 / 多重比较。  
2. 强制写清：**作用对象 → 原假设或对照 → 输出如何支持论文哪句结论**。  
3. 数值解读句式：  
   - 「在 H0: … 下，p=…，按 α=… **拒绝/不拒绝**；这意味着…；**不能**解释为…」  
4. 若论文误用（如正态性未检却小样本 t 检验、时序随机 CV），在「局限」中明确标出，语气具体不嘲讽。  
5. 打不开对应条目时，仍按 SKILL 主模板 3.1–3.5 写全，并标注「非常规检验，已按论文定义解释」。
