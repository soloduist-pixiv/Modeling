## 1. 评价与决策类

### 1.1 层次分析法 AHP

- **概念**：把多准则决策拆成层次，用两两比较得到权重，再综合方案得分。  
- **思路**：人对「两两谁更重要」比「直接打 100 分权重」更稳；用特征向量从比较矩阵提取权重。  
- **起效**：比较矩阵近似一致时，主特征向量给出可解释权重；一致性比率 CR 控制主观随意性。  
- **优点**：结构清晰、可纳入专家知识、适合指标难客观量化时。  
- **局限**：判断矩阵主观；方案/指标一变要重做；CR 合格≠权重客观；不宜假装成「数据驱动发现」。

### 1.2 熵权法

- **概念**：用指标在样本间的变异信息（熵）定客观权重：差异越大权重越大。  
- **思路**：区分度高的指标对排序更有信息量。  
- **起效**：归一化 → 概率化 → 信息熵 → 差异系数 → 权重。  
- **优点**：少主观、计算简单、适合多指标综合评价的客观加权。  
- **局限**：变异≠重要性（关键但几乎恒定的指标会被压权）；受异常值与量纲处理影响；定和/比例数据需先恰当变换。

### 1.3 TOPSIS

- **概念**：理想解逼近法——距正理想解近、距负理想解远则优。  
- **思路**：把方案放在加权指标空间里做几何排序。  
- **起效**：标准化 → 加权 → 正/负理想点 → 相对贴近度。  
- **优点**：直观、可解释、易与熵权/AHP 耦合。  
- **局限**：依赖权重与标准化；指标相关时几何距离重复计数；「理想点」随样本集会变，跨期比较需小心。

### 1.4 灰色关联分析

- **概念**：用序列曲线形状相似度衡量关联强弱。  
- **思路**：小样本、信息不完全时，看走势像不像。  
- **起效**：无量纲化 → 差序列 → 关联系数 → 关联度。  
- **优点**：对样本量要求相对宽松、计算轻。  
- **局限**：分辨系数主观；关联≠因果；对预处理敏感；理论地位常被高估。

## 2. 回归与解释类

### 2.1 线性回归 / 多元回归

- **概念**：用线性组合解释或预测连续响应。  
- **思路**：最小二乘找使残差平方和最小的超平面。  
- **起效**：在线性、误差独立同分布（及推断所需的更多假设）下，系数有明确边际含义。  
- **优点**：可解释、可做推断、是一切复杂模型的基线。  
- **局限**：线性假设；共线性扭曲系数；异常值杠杆大；相关仍非因果。

### 2.2 Ridge / Lasso / Elastic Net

- **概念**：在损失上加系数惩罚：Ridge 缩减，Lasso 可稀疏，EN 折中。  
- **思路**：用偏差换方差，处理共线与高维。  
- **起效**：惩罚项改变最优条件，系数被压缩（Lasso 可到 0）。  
- **优点**：高维/共线下更稳；Lasso 兼做选择。  
- **局限**：惩罚参数需验证集/CV；系数解释变「Shrinkage 后」；选中集合不稳定时勿过度叙事。

### 2.3 Logistic / Softmax 回归

- **概念**：对类别概率建模，用对数几率连接线性预测。  
- **思路**：把线性得分压到 (0,1) 概率。  
- **起效**：极大似然估计系数；阈值或概率用于分类。  
- **优点**：概率可解释、系数可谈几率比（注意条件）。  
- **局限**：线性可分时需正则；类别不平衡要改阈值/损失；多类时假设结构要说清。

### 2.4 广义线性模型 GLM / 分段、交互

- **概念**：扩展「线性预测子 + 链接函数 + 指数族误差」。  
- **思路**：让均值结构匹配数据支撑（计数、比例等）。  
- **起效**：正确的链接与方差函数使估计与检验更贴数据生成过程。  
- **优点**：比硬套 OLS 更诚实。  
- **局限**：链接选错则解释全歪；过离散、零膨胀等要另处理。

## 3. 时间序列类

### 3.1 ARIMA / SARIMA

- **概念**：用自回归、差分、滑动平均刻画平稳或可差分平稳序列（季节版加季节算子）。  
- **思路**：今天的值由过去值与过去冲击驱动。  
- **起效**：识别 d/D → 定阶 → 估计 → 残差白噪声检验 → 预报。  
- **优点**：经典、可解释成分、短序列上常够用。  
- **局限**：非线性/结构突变吃力；需防未来信息泄漏；外生回归版（ARIMAX）要小心内生性。

### 3.2 指数平滑 / Prophet 类

- **概念**：水平、趋势、季节的状态平滑或可加分解预报。  
- **思路**：近期权重更大；或显式分解趋势季节节假日。  
- **起效**：递推更新或贝叶斯/最大后验拟合分量。  
- **优点**：强季节、业务日历场景好用；实现快。  
- **局限**：机理解释弱；变点与节假日效应易过拟合；仍要持出验证。

## 4. 分类、聚类与降维

### 4.1 决策树 / 随机森林 / 提升树

- **概念**：树用分割逼近分区；RF 装袋降方差；Boosting 串行纠错。  
- **思路**：用可解释规则或集成降低偏差/方差。  
- **起效**：特征空间递归划分；集成靠投票/加权。  
- **优点**：非线性、交互好处理；树规则可抽。  
- **局限**：RF/Boosting 解释变难；泄漏与调参幻觉常见；小样本高维易过拟合。

### 4.2 K-means / 层次聚类 / DBSCAN

- **概念**：按距离或密度给无标签样本分组。  
- **思路**：组内更像、组间更不像。  
- **起效**：K-means 靠质心迭代；层次靠链接准则；DBSCAN 靠密度连通。  
- **优点**：探索结构、亚类分析常用。  
- **局限**：距离与标准化决定一切；K 难定；定和成分数据要先 CLR/ILR；稳定性需 bootstrap/重采样支持。

### 4.3 PCA / 因子分析

- **概念**：用少数主成分概括方差；因子模型强调潜在构造。  
- **思路**：相关变量背后可能有共同驱动。  
- **起效**：特征分解/SVD；载荷解释方向。  
- **优点**：降维、可视化、构权（需慎重）。  
- **局限**：主成分≠因果因子；符号与命名主观；方差最大方向未必是决策相关方向。

## 5. 优化与运筹类

### 5.1 线性规划 LP / 整数规划 MILP

- **概念**：在线性约束下优化线性目标；整数约束刻画是非/调度。  
- **思路**：可行域多面体（+整数格点）上求最优。  
- **起效**：单纯形/内点或分支定界等求解器保证（在可解规模内）最优或界。  
- **优点**：约束与目标清晰、结论可审计。  
- **局限**：线性近似现实；大数据下求解难；参数不确定时要做灵敏度或鲁棒优化。

### 5.2 动态规划 DP

- **概念**：最优子结构 + 重叠子问题，阶段决策。  
- **思路**：大问题拆阶段，状态转移。  
- **起效**：Bellman 方程递推。  
- **优点**：路径/背包/资源分配经典。  
- **局限**：状态维数爆炸；建模状态定义是艺术也是坑。

### 5.3 元启发式（GA / PSO / SA 等）

- **概念**：用种群或随机搜索近似难解黑盒/非凸问题。  
- **思路**：探索—开发权衡，不保证全局最优。  
- **起效**：迭代变异/交叉/速度更新等产生候选解。  
- **优点**：模型灵活、易接复杂约束（软约束）。  
- **局限**：不可复现风险；参数敏感；必须有简单基线与多次随机种子；论文里常被滥用炫技。

## 6. 评价—预测耦合与机器学习杂项

### 6.1 神经网络（含 MLP / 简单深度学习）

- **概念**：多层非线性函数逼近。  
- **思路**：用数据拟合复杂映射。  
- **起效**：反向传播最小化损失。  
- **优点**：高维非线性表达力强。  
- **局限**：数模竞赛小样本常不划算；解释差；必须严格隔离测试、报告复杂度预算。

### 6.2 支持向量机 SVM

- **概念**：最大间隔分类（或回归 SVR）。  
- **思路**：只由支持向量决定边界。  
- **起效**：对偶问题 + 核技巧映到高维。  
- **优点**：中小样本、高维尚可。  
- **局限**：核与 C 敏感；概率输出非原生；规模大时慢。

### 6.3 组合评价 / 耦合模型（「熵权-TOPSIS」「PCA-BP」等）

- **讲解时强制三问**：  
  1. 前半模块输出什么、后半输入什么？  
  2. 耦合解决了单模块的哪个缺陷？  
  3. 耦合是否引入新的双重计算/泄漏/不可解释？  
- **原则**：耦合不是加分项；说不清接口就按「堆砌」批评。

## 7. 数据预处理（常被论文写成「模型」）

| 方法 | 一句话 | 讲解时要点 |
|------|--------|------------|
| Min-Max / Z-score | 消量纲 | 是否在训练集拟合；是否泄漏 |
| 对数/Box-Cox | 减偏态 | 解释落在变换空间 |
| CLR/ILR（成分数据） | 打破定和约束 | 原始相关会假相关 |
| 缺失插补 | 填补空洞 | 机制（MCAR/MAR）与下游偏差 |
| 异常值处理 | 降杠杆 | 删点是否按规则预注册 |

预处理若影响结论，必须在导读里升格为独立「方法块」讲解。
