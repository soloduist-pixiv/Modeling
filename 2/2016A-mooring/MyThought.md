# MyThought — 2016 国赛 A 题：系泊系统的设计

## 1. Goal

在给定浮标–钢管–钢桶–重物球–锚链–锚的结构下，确定锚链型号/长度与重物球质量，使：
- 浮标吃水深度尽可能小
- 浮标游动区域（水平偏移）尽可能小
- 钢桶倾斜角尽可能小
并满足硬约束：锚链末端与海床夹角 ≤ 16°；钢桶倾斜角理想 ≤ 5°。

交付物：问题1–3 的数值结果表、锚链形状、设计方案与敏感性分析。

## 2. Constraints（题面硬约束）

| 约束 | 阈值 |
|------|------|
| 锚–海床切线角 | ≤ 16° |
| 钢桶倾斜角（工作效果） | ≤ 5°（软目标→设计硬约束） |
| 水深 | Q1/Q2: 18 m；Q3: 16–20 m |
| 风速 | Q1: 12/24；Q2/Q3: ≤36 m/s |
| 流速 | Q3: ≤1.5 m/s |
| 锚链型号 | I–V（附表） |
| 钢管 | 4×1 m，φ50 mm，10 kg/节 |
| 钢桶 | L=1 m，外径 0.3 m，总质量 100 kg |
| 浮标 | φ2 m，高 2 m，1000 kg |
| 锚 | 600 kg（视为固定于海床） |

荷载公式：
- 风：\(F_w=0.625\,S v^2\) (N)
- 流：\(F_c=374\,S v^2\) (N)

## 3. Data inventory

| 存在 | 不存在 / 需建模假设 |
|------|---------------------|
| 几何、质量、锚链单位质量 | 浮标材质分布、重心精确位置 |
| 风/流经验公式 | 三维海流剖面、波浪、涡激 |
| 平坦海床、海水密度 1025 kg/m³ | 锚抓力细节（以切线角约束代替） |
| — | 时间序列数据（本题为静力学设计） |

## 4. Hidden assumptions（待检验）

1. 静水平衡，忽略波浪与动力响应。
2. 各构件视为刚性直杆/圆柱；铰接无摩擦。
3. 浮标吃水面水平，风投影面积 = 直径 × 干舷；流投影取迎流侧投影。
4. 钢管/钢桶完全浸没（吃水足够时）；锚链可部分趴链于海床。
5. 重物球视为集中质量，体积按钢密度估算浮力或忽略体积（敏感性）。
6. 重力加速度 g=9.8 m/s²；浮力 = ρgV。
7. 水流沿水深均匀（题面未给剖面）。

## 5. Success criteria（预注册指标）

| 指标 | 角色 | 阈值 δ |
|------|------|--------|
| θ_barrel（钢桶倾角） | 主 | ≤5° 为设计通过；比较时 Δ≥0.5° 视为有意义 |
| φ_anchor（锚端切线角） | 硬约束 | ≤16°；比较时 Δ≥1° |
| R_swim（游动半径/水平偏移） | 主（多目标） | 越小越好；Δ≥0.1 m |
| d_draft（吃水） | 次 | 越小越好；Δ≥0.05 m |
| 约束可行性 | 门控 | 不可行方案直接淘汰 |

Pareto 意图：先满足硬约束，再在 (θ_barrel, R_swim, d_draft) 上非支配优选；复杂度惩罚：同等指标下取更少自由参数。

## 6. 答題清单

| 子问 | 交付物（可检查） |
|------|------------------|
| Q1a 风速 12 m/s | 钢桶+4 节钢管倾角、锚链形状、吃水、游动区域 |
| Q1b 风速 24 m/s | 同上 |
| Q2a 风速 36 m/s（球重 1200 kg） | 同上，并报告是否违约束 |

## 7. 题型分类

- **原子问题 Q1**：类型 **G Simulation / 静力机构**；交付：给定参数下的平衡态几何与倾角。
- **原子问题 Q2**：类型 **C Optimize**（单参数球重）+ G；交付：可行球重与对应态。
- **原子问题 Q3**：类型 **C Optimize**（型号×链长×球重）+ G；交付：设计方案 + 情景表。

审查重点：力平衡闭合、趴链判定、风/流投影面积与吃水耦合、无“数据泄漏”（本题无统计学习，对应为：禁止用全水深情景调参后再声称验证同一情景而不留 hold-out 情景）。

禁止的伪三方案：三种仅差离散步长的同一刚体链模型；或仅改求解器容差。

## 8. 候选池（跨机制族）

### 方案 A（机制族：离散多刚体静力 / 基线）
- 回答：Q1–Q3 状态求解
- 核心假设：锚链按节长离散为等长刚性链环，铰接；整体平面静力平衡
- 方法：由下而上或打靶法求铰接角，迭代吃水使竖直力平衡
- 相对基线：自身即基线
- 局限：链环数大时计算重；忽略链环弯曲柔性细节
- Failure Modes：高风速无平衡（抬锚/过仰）；趴链与悬链切换奇异
- 复杂度：中；失败退回：解析悬链近似

### 方案 B（机制族：连续悬链线 + 刚性杆段）
- 回答：Q1–Q3；对照 A
- 核心假设：锚链为均匀悬链（或分段有/无趴链），钢管/钢桶为刚性
- 方法：悬链解析 + 边界匹配锚角/水平张力
- 拟解决 A 的问题：减少离散误差、便于灵敏度
- 局限：与真实有档/无档链几何有偏差
- Failure Modes：短链接近直线时数值病态
- 复杂度：低–中；失败退回 A

### 方案 C（机制族：约束优化 / 设计搜索）
- 回答：Q2–Q3
- 核心假设：状态由 A 或 B 的正演给出，设计变量离散+连续
- 方法：网格/二分球重；Q3 对型号×链长×球重做约束多目标搜索
- 拟解决：把“尽量小”落到可检验的可行集与 Pareto 前沿
- 局限：依赖正演精度；情景组合爆炸需情景代表点
- Failure Modes：可行域空；过拟合某一极端风速
- 复杂度：中；失败退回：手工工程规则（加球→减倾角）

## 9. Attribution 问题清单

1. A 与 B 主指标分歧时，先查：趴链判定 / 重物球浮力 / 投影面积是否随倾角修正。
2. 极端：无风时应倾角≈0、吃水由重力–浮力决定，A/B 应一致；强风短链时可能分歧。
3. 删掉“链环精细离散”后，悬链 B 是否仍能答完题面（预期：能）。

决策预置：以 **A 为报告主模型**，B 作对照与误差条；C 用于 Q2/Q3 设计。

## 10. Handoff → Experiment

- 基线：方案 A，先算 Q1 静止海水 + 12/24 m/s。
- 指标按 §5。
- 泄漏审计：本题为机理正演；设计搜索的验证情景与训练情景分离（Q3 留部分 (水深,风速,流速) 组合作 hold-out 报告）。

## 11. 事后修订记录（F3）

以下几点在实验过程中偏离了上面的初始计划，原因记录于此：

1. **§4 假设 5 被收紧。** 初始计划把"忽略重物球体积"列为可接受的备选；实测其浮力影响
   Δθ=0.72°、阻力影响 Δφ=2.35°，两者都超过预注册阈值，因此浮力与阻力都成为必选模块。
2. **§7 对 Q3 的分类由"C Optimize"细化为"最劣情景鲁棒设计"。** 初始计划打算用
   "训练情景 + hold-out 情景"的机器学习式划分来防泄漏；但本题环境是连续箱体而非样本集，
   更恰当的做法是用单调性把最劣值归约到角点，再用稠密扫描独立复核归约本身。
   hold-out 的角色因此由"防过拟合"变为"验证归约"。
3. **新增一条初始计划中没有的解析结果。** 推导中发现钢桶顶端竖向拉力与球重、链型无关，
   由此得到与设计无关的吃水下界。这条结果反过来决定了论文的叙事主线——
   Q3 的真正冲突不在锚链，而在浮标储备浮力。
4. **§5 的 Pareto 意图被扩展。** 初始计划只打算"非支配优选 + 复杂度惩罚"；
   实际交付中补上了熵权 TOPSIS、权重随机化与机会约束，因为单纯的非支配集有 24 个点，
   不给排序等于不回答"请给出设计"。
