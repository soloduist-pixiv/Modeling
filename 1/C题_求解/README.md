### 核心结论速览

1. **风化**：Fisher/置换检验确认风化与类型相关（`p=0.0113`）；风化前还原改为文物级、分类型的收缩 CLR 位移。
2. **分类**：所有验证按文物编号分组，阈值在每一训练折内重新寻优；亚类先校正风化，再在文物级 CLR 空间聚类。
3. **未知样品**：A1/A6/A7 → 高钾；A2/A3/A4/A5/A8 → 铅钡；另报告文物 bootstrap 区间、扰动翻转率和适用域，A2 需谨慎外推。
4. **关联**：主指标改为控制风化后的比例协调系数；分层整体置换确认两类关联结构不同（`p=0.002`，8 对差异通过 FDR）。

### 本轮方法学修复

- 消除同一文物多采样点造成的伪重复与交叉验证泄漏。
- 统一聚类训练、未知亚类归属和风化校正所使用的 CLR 几何。
- 不再把未经外部校准的树投票称为“概率”，改称模型支持度。
- 删除无效的“打乱相关矩阵上三角元素”Mantel 实现，改用保持风化分层结构的标签置换。
