# DataAudit — 2016A 系泊系统

## 1. 数据概况

本题无统计样本表，输入为题面参数与经验荷载公式。

| 项 | 内容 |
|----|------|
| 样本性质 | 机理静力设计；情景参数网格 |
| 几何/质量 | 浮标、4 节钢管、钢桶、重物球、锚链 I–V、锚 |
| 环境情景 | 水深、风速、流速（Q3 区间） |
| 缺失 | 波浪、流剖面、动力系数、锚抓力曲线 |

## 2. 粒度

- 状态求解粒度：单个静力平衡构型（平面）。
- 设计粒度：型号 × 链长 × 球质量 × 情景。
- 标签：无监督学习标签；约束为题面阈值。

## 3. 题面可编码规则

- φ_anchor ≤ 16°；θ_barrel ≤ 5°（设计目标升格为硬约束）。
- \(F_w=0.625 S v^2\)，\(F_c=374 S v^2\)。
- 海水密度 1025 kg/m³；Q1/Q2 水深 18 m 平坦海床。

## 4. 结构特征

- 多体串联铰接 + 可趴链的重锚链。
- 吃水 ↔ 风力投影面积强耦合（设计杠杆）。
- 无成分数据/面板文本。

## 5. 泄漏表面（机理问题对应）

| 风险 | 处理 |
|------|------|
| 用待报情景调参后再声称“验证”同一情景 | Q3 设计用 train 情景，hold-out 情景只评估 |
| 全数据拟合归一化 | 不适用 |
| 时序随机划分 | 不适用 |

结论：**泄漏扫描通过**（hold-out 情景独立评估）。

## 6. 描述性检查（能否支撑提问）

- 给定参数可闭合竖直/水平力平衡与几何水深约束 → 可答 Q1。
- 球重单调降低倾角（扫描可见）→ 可答 Q2。
- 型号/链长/球重网格存在可行域 → 可答 Q3；极端重球可能使吃水逼近 2 m（Failure Mode）。

## 7. 基线建议

离散多刚体静力（Family A）为必报基线；连续悬链（B）对照；网格约束搜索（C）服务 Q2/Q3。
