# 2016A 系泊系统的设计 — 问题理解

## 1. 目标

在给定海况与结构参数下，计算/设计系泊系统，使：
- 钢桶倾角 ≤ 5°（设备工况）
- 锚链锚点切线与海床夹角 ≤ 16°（防拖锚）
- 浮标吃水深度、游动区域尽可能小（设计优化目标）

## 2. 约束与已知参数

| 构件 | 参数 |
|------|------|
| 浮标 | 圆柱 d=2m, h=2m, m=1000kg |
| 钢管×4 | L=1m, d=50mm, m=10kg/节 |
| 钢桶 | L=1m, d=30cm, m=100kg |
| 重物球 | 可调（题1/2 默认 1200kg） |
| 锚链 II 型 | 22.05m, 7kg/m |
| 锚 | 600kg |
| 水深 | 18m（题3: 16–20m） |
| 海水密度 | 1025 kg/m³ |

风荷载：$F_w=0.625Sv^2$；水流力：$F_c=374Sv^2$（S 为法向投影面积）。

## 3. 数据

本题无外部数据集；参数均由题面给定。实验输出存于 `results/`。

## 4. 成功指标（预注册）

| 指标 | 含义 | 阈值 δ |
|------|------|--------|
| 钢桶倾角 | 与竖直线夹角 | ≤5° |
| 锚角 | 链-海床夹角 | ≤16° |
| 游动半径 | 浮标水平位移 | 越小越好（Pareto） |
| 吃水 | 浮标浸深 | 越小越好（Pareto） |

## 5. 答題清单

| 编号 | 交付物 |
|------|--------|
| Q1 | 风速 12/24 m/s：各节倾角、链形、吃水、游动区域 |
| Q2 | 风速 36 m/s：同上 + 重物球质量调节满足约束 |
| Q3 | 考虑风/流/水深的设计方案 + 多工况分析表 |

## 6. 题型分类

- **Q1/Q2**：G 仿真（静力平衡）+ D 机理（张力传播）
- **Q2**：C 优化（重物球质量一维搜索）
- **Q3**：C 多目标设计（链型/链长/重球 Pareto）

### 候选池（跨族）

| 方案 | 机制族 | 角色 |
|------|--------|------|
| M0 直杆近似 | 几何静力基线 | 基线 A |
| M1 张力传播+悬链线 | 经典静力学+悬链线 | 主模型 B |
| M2 约束网格+Pareto | 离散优化 | 对比 C |

禁止伪三方案：不同链型但同一悬链线框架不算三族。

## 7. 审查重点

- 悬链线贴底段与全悬空段分支
- 浮标吃水与竖向力平衡耦合
- 题3 最坏工况（浅水+大风+大流）可行性
